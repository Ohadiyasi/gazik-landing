# فَتی بادومی | Fati Badoomi

پروتوتایپ لندینگ فارسی، راست‌به‌چپ و واکنش‌گرا برای برند کره بادام‌زمینی؛ با HTML، CSS و JavaScript خالص. بدون بکند، پکیج، مرحله build یا سرویس خارجی در زمان اجرا.

## اجرا

فایل `index.html` را در مرورگر باز کنید، یا از ریشه پروژه اجرا کنید:

```sh
python3 -m http.server 4173
```

سپس آدرس `http://localhost:4173` را باز کنید.

## انتشار روی GitHub Pages

1. یک مخزن GitHub بسازید و فایل‌های این پروژه را به شاخه `main` بفرستید.
2. در مخزن، `Settings → Pages` را باز کنید.
3. منبع انتشار را `Deploy from a branch` انتخاب کنید.
4. شاخه `main` و پوشه `/(root)` را انتخاب کرده و ذخیره کنید.

همه مسیرها نسبی هستند؛ پروژه هم روی دامنه اصلی و هم در مسیر `username.github.io/repository-name/` اجرا می‌شود. فایل `.nojekyll` نیز موجود است. هیچ متغیر محیطی، کلید API یا build لازم نیست.

## بخش‌ها و تعامل‌ها

- خانه: معرفی برند، تصویر اصلی اختصاصی و دعوت به کشف طعم‌ها
- طعم‌ها: سه طرح پیشنهادی بسته‌بندی؛ باز شدن جزئیات هر محصول در پنجره محاوره‌ای
- داستان ما: روایت «از کارخانه به خانه» و کاراکتر اختصاصی بادام‌زمینی
- ایده‌های مصرف و مجله: سه مقاله نمونه قابل خواندن
- ارتباط با ما: وضعیت شفاف آماده‌سازی راه‌های ارتباطی
- منوی موبایل، ناوبری داخلی، بستن پنجره با Escape و کلیک بیرون، بازگشت تمرکز صفحه‌کلید، پشتیبانی از کاهش حرکت

## فایل‌های اصلی

| فایل | کاربرد |
| --- | --- |
| `index.html` | ساختار صفحه و متن‌ها |
| `styles.css` | پالت رنگی، طراحی و اندازه‌های واکنش‌گرا |
| `script.js` | منو، جزئیات محصولات، مقاله‌ها و پنجره ارتباط |
| `assets/` | تصاویر، آیکون‌ها، تصویرسازی و فونت محلی |
| `ASSETS.md` | منشأ تصویر، پرامپت تولید و مجوز فونت |

## محدوده پروتوتایپ

نام «فَتی بادومی» از نام پوشه پروژه گرفته شده است. طعم‌ها، بسته‌بندی‌ها، داستان و مقالات، محتوای پیشنهادی طراحی هستند و باید با اطلاعات نهایی برند جایگزین شوند. فروشگاه، سبد خرید، پرداخت و ارسال فرم پیاده‌سازی نشده‌اند. هیچ قیمت، شماره تماس، نظر مشتری یا ادعای تغذیه‌ای ساختگی درج نشده است.

رنگ‌ها در ابتدای `styles.css` به‌صورت متغیر تعریف شده‌اند: `#303E9C`، `#E7B53E`، `#27854B`، `#EF4545`، `#151515`، `#FFF5DE` و `#C68B57`.
